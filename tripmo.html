About the Project

A comprehensive commuter guide application concept designed to assist local residents and tourists in navigating public transportation within Cavite, Philippines. The Figma prototype demonstrates a user-friendly interface that prioritizes convenient travel through several core features:

  • Smart Routing: Provides recommended transportation routes, destination searching, and terminal/stop markers.
  • Commuter Utilities: Features integrated route planning, simulated real-time navigation guides, and transparent fare tracking.
