About the Project

A retro game-inspired automata simulator developed as the final project for an Automata Theory and Formal Languages course. This web application visualizes the Deterministic Finite Automaton (DFA), Context-Free Grammar (CFG), and Pushdown Automaton (PDA) derived from two given regular expressions. It includes an interactive simulation engine that allows users to input, validate, and trace strings through the generated automata step-by-step.
